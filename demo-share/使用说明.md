# SME-I 前端演示包

这是已构建好的离线前端 Demo，不包含源码、后端服务、账号或密钥。内置的演示数据保存在当前浏览器页面会话内，刷新后重置。

## Windows 上启动

1. 解压整个 ZIP，保持 `dist` 文件夹与 `server.mjs` 在同一目录。
2. 电脑需已安装 Node.js。双击 `启动演示.bat`；也可以在解压目录打开终端，运行 `node server.mjs`。
3. 打开 `http://127.0.0.1:4173/`。工作台可直接访问 `http://127.0.0.1:4173/app/overview?month=2026-06`。
4. 体验顺序：数据采集 → 记账 → 经营分析 → AI 问答。关闭终端或按 Ctrl+C 即停止服务。

`127.0.0.1` 只在运行 Demo 的电脑上有效。请把 ZIP 文件发给队友，让对方在自己的电脑上启动；不要直接把你电脑上的本地网址当作远程分享链接。不要直接双击 `dist/index.html`，因为浏览器路由需要本地服务。

本包使用固定演示数据和确定性问答，没有连接真实后端或 AI 模型。票据 OCR、主动预警、成员管理、备份和导出是预留能力，当前演示不表示这些服务已经实现。项目源码与接口对接文档请另行从原项目目录分享。
