## Web 与微信小程序差距评估

原报告一期目标为微信小程序 + 云函数 + 云数据库。当前工程为 Vue 3 + Vite Web 前端。差距：
- Vue DOM 组件与小程序组件不可直接复用
- 可共享：字段契约、校验规则、指标定义、文案和部分无平台依赖逻辑
- Web 响应式不能直接称为已完成微信小程序
- 小程序一期需单独实现与验证

## 安全核对

- 所有组件只调用 src/services/api 领域方法，不拼 URL、不绑定云厂商 SDK
- 不在前端保存 API Key/密码/长期令牌
- 不把演示数据或占位页面呈现为真实服务已完成
- 导出下载 URL 不附加 bearer token
- 破坏性操作（恢复/删除）需预览影响范围并确认主体名称后才执行
